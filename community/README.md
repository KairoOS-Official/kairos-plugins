# 👥 Plugins Communautaires Vérifiés

Ici vous trouverez les plugins créés par la communauté et validés par l'équipe KaïroOS après audit de sécurité.

## ✨ Caractéristiques
- **Créations de la communauté** : fonctionnalités, intégrations et outils variés.
- **Vérification sandbox** : le code et les permissions ont été relus avant intégration.
- **Installation directe** depuis l'onglet **Communauté** dans KaïroOS.

## 🚀 Proposer un plugin
Pour soumettre votre plugin dans cette section :
1. Testez d'abord votre plugin (voir le guide dans `../PLUGIN_GUIDE.md`).
2. Ouvrez une Pull Request en ajoutant votre dossier dans `community/{votre-plugin}/`.
3. Une fois validé par l'équipe, il apparaîtra directement dans l'onglet Communauté de KaïroOS.
