# 🛡️ Plugins Officiels KaïroOS

Ici vous trouverez tous les plugins développés, testés et officiellement certifiés par l'équipe KaïroOS.

## ✨ Garanties
- **Compatibilité assurée** avec les versions stables de KaïroOS.
- **Sécurité auditée** : permissions sandbox strictement vérifiées.
- **Maintenance active** : mises à jour et correctifs assurés par l'équipe officielle.

## 📂 Organisation
Chaque sous-dossier correspond à un plugin officiel contenant au minimum :
- `plugin.json` : manifeste décrivant le plugin, sa version et ses permissions requises.
- Le code source / point d'entrée du plugin.
